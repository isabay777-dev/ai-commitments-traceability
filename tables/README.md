# Экспонаты v2

Сборка: `Rscript scripts/34_models_v2.R`, `Rscript scripts/35_governance_v2.R`, `python3 scripts/36_tables_v2.py` из корня проекта. Затем запустить `scripts/37_build_docx_v2.py` интерпретатором Python с python-docx и доступным pandoc: он создаёт Word-файлы. Первые два скрипта экспортируют точные коэффициенты и фактические выборки; третий собирает русские рабочие экспонаты. Tables_I_IV.md / .docx — отдельный файл таблиц; CSV — данные панелей; Figure_1.md / .docx — рисунок и рабочее примечание; TIFF/EPS — экспорт для подачи, PNG — предпросмотр. Supplementary Figure S1 — дополнительный график сырой панели, не Figure 1. F2 принят по C-primary; F/A/B/C сохранены как история. Source manifest содержит SHA-256 входов. После изменения исходов сначала повторить R, затем Python.
